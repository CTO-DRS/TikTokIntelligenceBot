# 📖 دليل المستخدم — بوت تيك توك للاستخبارات

> الإصدار: 1.0 — آخر تحديث: 2026-10
> هذا الدليل موجّه للمستخدم النهائي. لتفاصيل تقنية راجع `API_DOCUMENTATION.md`، وللنشر راجع `DEPLOYMENT_GUIDE.md`.

---

## 1. مقدمة

**بوت تيك توك للاستخبارات** هو بوت تيليجرام يحلّل الحسابات العامة على تيك توك ويقدّم تقارير مفصّلة بالعربية والإنجليزية. يعمل البوت على **البيانات العامة فقط** التي يعرضها أي زائر على صفحة الحساب، ولا يخترق أي حساب ولا يصل إلى بيانات خاصة، ولا يخترع بيانات — أي حقل لا يمكن الحصول عليه قانونياً يُعرض كـ **«غير متوفر»** مع السبب.

ما يميّز البوت عن أدوات «السحر الأسود» المنتشرة:
- شفافية كاملة: كل حقل موسوم بحالته (متاح ✅ / تقديري 🧮 / غير متوفر ⛔).
- تحليلات رياضية حقيقية (معدل تفاعل، أفضل أوقات نشر، تحليل هاشتاقات) وليس أرقاماً عشوائية.
- تتبع زمني يبني سجل نمو المتابعين عبر الـ snapshots ثم يرسم منحنى 30 يوماً.

### 1.1 ماذا يمكن أن تعرف عن أي حساب عام؟

| المعلومة | الحالة |
|---|---|
| الاسم، المعرّف، النبذة، الصورة، التوثيق، عام/خاص، البلد المعلن | ✅ متاح |
| المتابعون، المتابَعون، الإعجابات الكلية، عدد الفيديوهات | ✅ متاح |
| آخر 30 فيديو: مشاهدات، إعجابات، تعليقات، مشاركات، حفظ، مدة، موسيقى، هاشتاقات | ✅ متاح |
| معدل التفاعل، متوسط المشاهدات، أفضل أوقات النشر، الكلمات المفتاحية، تصنيف المحتوى | ✅ محسوب |
| الإيميل/الهاتف **المكتوبة صراحة في النبذة** أو روابط منصات أخرى | ⚠️ إن وُجدت فقط |
| نمو المتابعين (منحنى 30 يوم) | 🧮 تدريجي — يبني عبر `/track` |
| نسبة الحسابات المزيفة (إرشادي) | 🧮 تقدير منخفض الثقة |
| الجمهور حسب الدولة/العمر/الجنس | 🧮 تقدير عام منخفض الثقة (تيك توك لا يشاركها إلا لصاحب الحساب) |
| IP الإنشاء، GPS، إيميل/هاتف التسجيل، Device ID، Session ID، كلمة المرور، سجل الاختراق، سجل أسماء المستخدمين | ⛔ غير متوفر — بيانات سيرفرية خاصة، لا يوجد API عام لها، ومحاولة الحصول عليها مخالفة قانونية |

## 2. البدء

### 2.1 أول تشغيل
1. افتح محادثة مع البوت (الرابط الذي يوفّره مالك البوت).
2. أرسل `/start` — ستظهر القائمة الرئيسية بأزرار داخلية.
3. اختر لغتك من `/settings` → اللغة (العربية افتراضياً، مع دعم RTL كامل).

### 2.2 مستويات التفصيل الثلاثة
من `/settings` → «مستوى التفصيل»:
| المستوى | لمن؟ | ماذا يعرض؟ |
|---|---|---|
| `مبسط basic` | المستخدم العادي | الأساسيات فقط: الاسم، المتابعون، الإعجابات، أبرز الأرقام |
| `متقدم advanced` | الأغلبية | كل الأقسام مع التحليلات والحسابات |
| `خبير full` | المحللون | كل شيء + عناصر تقنية + ملاحظات التوفر والثقة لكل حقل |

## 3. الأوامر الـ 17

### 3.1 أوامر الفحص
| الأمر | الصيغة | الوصف |
|---|---|---|
| `/scan` | `/scan username` أو `/scan @username` أو رابط فيديو | فحص فوري للحساب وفق مستوى التفصيل المختار |
| `/deepscan` | `/deepscan username` | فحص عميق: تحليل 30 فيديو، أفضل الأوقات، الهاشتاقات، الكلمات المفتاحية، تصنيف المحتوى، الموسيقى، تحليل أمني للحساب |
| `/bulk` | `/bulk user1 user2 ...` | فحص جماعي حتى 25 حساباً — كل نتيجة في رسالة منفصلة |
| `/compare` | `/compare user1 user2` | جدول مقارنة سطر-بسطر مع نسب الفرق |
| `/track` | `/track username` | تشغيل/إيقاف التتبع: تنبيهات تغيّر الاسم/النبذة/الصورة، التوثيق، فيديو جديد، تغيّر متابعين ±10% |

> 💡 يمكنك دائماً إرسال **رابط فيديو تيك توك** بدلاً من اسم المستخدم في `/scan`، وسيستخرج البوت الحساب منه.

### 3.2 أوامر التقارير والبيانات
| الأمر | الصيغة | الوصف |
|---|---|---|
| `/report` | `/report username [pdf|html|xlsx|json]` | توليد تقرير كامل وتحميله كملف. PDF عربي RTL، Excel يتضمن رسوماً بيانية |
| `/history` | `/history` | آخر 10 فحوصات أجريتها أنت مع التاريخ والنوع |
| `/export` | `/export` | تصدير كل بياناتك المخزنة (ملف JSON) — حقك في GDPR |
| `/stats` | `/stats` | إحصائيات استخدامك: عدد الفحوصات، آخر نشاط، التتبعات النشطة |

### 3.3 أوامر الإدارة (للمشرفين فقط)
| الأمر | الوصف |
|---|---|
| `/admin` | لوحة التحكم: زر «رسالة جماعية»، «تنظيف قديم»، حالة النظام |
| `/broadcast نص` | إرسال رسالة لكل المستخدمين (مع تأكيد قبل الإرسال) |
| `/block <telegram_id>` | حظر مستخدم |
| `/unblock <telegram_id>` | رفع الحظر |
| `/stats_all` | إحصائيات عامة: المستخدمون، الفحوصات، التتبعات |
| `/clean` | تنظيف البيانات الأقدم من مدة الاحتفاظ (30 يوماً افتراضياً) |

### 3.4 الإعدادات
| الأمر | الخيارات |
|---|---|
| `/settings` | اللغة (عربي/English) · مستوى التفصيل (3 مستويات) · تفعيل/تعطيل تنبيهات التتبع |

## 4. القوائم التفاعلية (3 مستويات)

`/start` يفتح نظام قوائم بأزرار داخلية:

```
🏠 القائمة الرئيسية
├── 🔎 فحص سريع
│   ├── أدخل اسم المستخدم… (يتحول إلى وضع انتظار الاسم)
│   └── 💡 إرسال رابط فيديو يعمل أيضاً
├── 🔬 فحص عميق
├── ⚖️ مقارنة      → أدخل: user1 user2
├── 🔔 التتبع
│   ├── قائمة تتبعاتي
│   └── ➕ إضافة تتبع
├── 📄 التقارير    → اختيار الصيغة ثم الحساب
├── 🗂 السجل
├── ⚙️ الإعدادات
│   ├── 🌐 اللغة
│   ├── 📊 مستوى التفصيل
│   └── 🔕 التنبيهات
└── 🛡 لوحة المشرف (تظهر للمشرفين فقط)
```

أزرار «رجوع» في كل مستوى، و«إغلاق» لإخفاء القائمة.

---

## 5. فهم نتيجة الفحص

كل قسم في النتيجة موسوم بـ:
- ✅ **متاح** — بيانات فعلية مُستخرجة الآن.
- 🧮 **تقديري** — نتيجة نموذج إحصائي على بيانات عامة، مع درجة ثقة (عالية/متوسطة/منخفضة).
- ⛔ **غير متوفر** — مع **سبب واضح** (مثال: «بيانات سيرفرية خاصة — لا يوجد API عام»).

مثال مقتطف:

```
📊 الإحصائيات
  المتابعون:        1.2M
  الإعجابات الكلية: 34.5M
  معدل التفاعل:     4.8% (جيد جداً لمستوى المتابعين)

📈 نمو المتابعين (30 يوم)
  🧮 تقديري — يحتاج ≥2 لقطات زمنية
  💡 فعّل /track username لبدء بناء السجل

📱 معلومات الجهاز والموقع
  ⛔ Device ID: غير متوفر — بيانات سيرفرية خاصة
  البلد المعلن (region): SA ✅
  المنطقة الزمنية (مستنتجة من region): Asia/Riyadh 🧮 (ثقة متوسطة)
```

### 5.1 مستويات الثقة في الاستدلال الجغرافي
وحدة الجغرافيا لا تعرف موقع المستخدم الحقيقي — بل تستنتج:
| المصدر | الثقة |
|---|---|
| حقل `region` من بيانات الملف | عالية |
| المنطقة الزمنية المستنتجة من region | متوسطة |
| تحليل لغة النبذة/الروابط | منخفضة |
| موقع إنشاء الفيديو (`locationCreated`) إن وُجد | متوسطة |

## 6. التتبع والتنبيهات

عند `/track username`:
- كل **10 دقائق** يفحص البوت الحساب وينبهك عند: تغيّر الاسم/النبذة/الصورة، الحصول على التوثيق أو إزالته، نشر فيديو جديد، تغيّر المتابعين **±10%**.
- كل **ساعة** تُسجَّل لقطة (snapshot) تُغذّي منحنى النمو 30 يوماً في التقارير.
- لإيقاف التتبع أعد إرسال `/track username` نفسه (تبديل تشغيل/إيقاف).
- عطّل التنبيهات مؤقتاً من `/settings` دون فقدان السجل.

## 7. التقارير

| الصيغة | الاستخدام الأمثل |
|---|---|
| `pdf` | عرض رسمي — عربي RTL، غلاف، جداول، منحنى النمو، إخلاء مسؤولية |
| `html` | فتح بالمتصفح — صفحة واحدة منسقة قابلة للطباعة |
| `xlsx` | العمل على البيانات — أوراق منفصلة + رسوم Excel أصلية |
| `json` | الربط البرمجي — بنية كاملة لكل البيانات والحالة لكل حقل |

الملفات تصل مباشرة في المحادثة وتُحفظ على السيرفر مدة قصيرة للتنزيل.

---

## 8. الخصوصية وحقوقك

- البوت يخزّن: معرّف تيليجرام، اسم المستخدم، لغتك، سجل أوامرك، نتائج فحوصاتك.
- `/export` يمنحك نسخة JSON كاملة من بياناتك، و`/clean` (للمشرف) يحذف القديم آلياً كل 30 يوماً (قابل للضبط).
- بياناتك المشفرة (مثل أسرار 2FA للمشرفين) تُشفَّر AES-256-GCM ولا تُعرض أبداً.
- لا تشارك البوت أي كلمة مرور أو رمز تحقق — **البوت لن يطلبها أبداً**.

## 9. الأسئلة الشائعة

**س: لماذا يظهر «غير متوفر» كثيراً في الأقسام المتقدمة؟**
ج: لأن تلك الحقول (IP، GPS، إيميل التسجيل، Device ID…) بيانات خاصة لا يوفرها أي API عام. البوت صادق بدل أن يبيعك بيانات ملفقة.

**س: الفحص يعطي «بيانات تجريبية» أحياناً — لماذا؟**
ج: إذا حجب تيك توك الطلبات (rate-limit)، يعرض البوت بيانات تجريبية **موسومة بوضوح** بدل الفشل الصامت، حتى تختبر الواجهة. أعد المحاولة بعد قليل للبيانات الحقيقية.

**س: متعمّدت كتابة `@` أو رابط كامل — يهم؟**
ج: لا. البوت ينظّف المدخل ويقبل: `username` / `@username` / رابط `/@user` / رابط فيديو.

**س: هل يمكن فحص حساب خاص (Private)؟**
ج: تظهر بياناته العامة فقط (الاسم، الصورة، المعرّف، حالة الخاص) وبدون أي محتوى.

**س: معدل التفاعل كيف يُحسب؟**
ج: مجموع (إعجابات + تعليقات + مشاركات + حفظ) على آخر فيديوهات ÷ متوسط المشاهدات — وليس على المتابعين، فهذا أدق واقعياً.

**س: البوت بطيء في الفحص العميق؟**
ج: `/deepscan` يجلب 30 فيديو ويحللها؛ قد يستغرق ثوانٍ. الحماية من الإغراق تمنع تكراره أكثر من 5 مرات/ساعة (قابلة للضبط من الإعدادات).

## 10. آداب الاستخدام
استخدم البوت للتحليل الشرعي (تسويق، بحث، صحافة، أمان). يُمنع: التتبع المسيء للأفراد، محاولة بناء ملفات شخصية للأطفال، أي استخدام يخالف شروط تيك توك أو قوانين بلدك (GDPR وغيرها). المالك مسؤول عن تشغيله وفق القوانين المحلية.
